# Limba platformei

Toate textele destinate utilizatorilor Marketz.ro trebuie scrise în română, cu diacritice: pagini, navigație, formulare, administrare, mesaje de eroare și succes, emailuri, metadate și documente pentru campanie.

Folosește formulări clare în română în locul termenilor englezești precum „shares”, „wallet”, „settlement” sau „trade”. Păstrează denumirile oficiale ale instituțiilor și produselor. Identificatorii din cod, numele variabilelor de mediu, rutele existente și contractele API nu se traduc.
